# Execution Scripts (Layer 3 - Tools)

Store deterministic Python scripts here.

Guidelines:
- Each script performs one well-defined task (e.g. data scraping, API calls, file conversions, cloud uploads).
- Load secrets and configurations from `.env`.
- Write clean, modular, and thoroughly commented code with clear input arguments (e.g., `argparse` or CLI flags).
- Maintain robust error handling and descriptive logging/exit codes.
