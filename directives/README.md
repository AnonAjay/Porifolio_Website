# Directives (Layer 1 - SOPs)

Store Standard Operating Procedures (SOPs) in Markdown format here.

Each directive should define:
- **Goal**: What this workflow achieves
- **Inputs**: Required data or environment parameters
- **Execution Tools**: Python scripts in `execution/` to run
- **Outputs / Deliverables**: What to produce and where it should be stored
- **Edge Cases & Failure Handling**: Known pitfalls, limits, or workarounds
