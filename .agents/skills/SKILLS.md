## How to Utilize These Skills in This Project

1. **Portfolio Sections & Aesthetics**:
   - Activate **`frontend-design`** and **`theme-factory`** when building or refining sections (Hero, About, Projects, Experience, Contact) to ensure standout typography, unique layouts, and cohesive color schemes.
2. **Component Architecture**:
   - Activate **`web-artifacts-builder`** to organize reusable, highly interactive components and animations.
3. **Automated Verification**:
   - Activate **`webapp-testing`** to spin up the local server, run browser checks, inspect console logs, and verify responsive design across mobile/desktop viewports.
